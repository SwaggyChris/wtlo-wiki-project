# WTLO Wiki Project

Clean Next.js project structure for a WTLO Wiki concept site.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vitest for lightweight checks

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run start
```

## Test
```bash
npm run test
```
